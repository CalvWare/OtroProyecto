Guía Rápida de HTML

  1. Estructura Basica

    HTML se basa basicamente en la estructura de la pagina, elementos dentro de otros elementos pero todos etiquetados para que tengan una funcion especifica, mas o menos como se lista a continuacion

    • Cuerpo general con HTML
    • Head que corresponde a los metadatos de la pagina
    • Body que es donde se programa la informacion y visual de la pagina

  2. Etiquetas más comunes

    Alguna etiquetas comunes, son: body, Head, H1,H2, H3, P de párrafo, ol listas ordenadas, ul listas desordenadas y li que corresponde a los elementos de una lista. Otras pueden ser como

    • El uso de negrilla con b
    • Poner adecuadamente los h1, h2, he, etc
    • Asegurarse de cerrar cada etiqueta con /

  3. Buenas Prácticas

    Definitivamente se requiee que cuando se trabaje con codigo html, se realice usando buenas practicas de desarrollo, como el orden de las etiquetas, el indentado de las lineas, etc y otras cosas, por ejemplo

    • Tener bien ordenado el codigo
    • Hacer comentarios continuamente para entender el codigo
    • Definitivamente trabajar con un control de cambios como GIT
